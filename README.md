# ClearDrive · demonstration

The ClearDrive client and dealer walkthrough, published as a static installable web app.

- Live: https://zikriaabdul-rgb.github.io/cleardrive/
- Guided tour: https://zikriaabdul-rgb.github.io/cleardrive/#tour
- Every screen carries "Demonstration · sample data". No backend, no real dealer messages, no live pricing.

Built from the `showcase/` source in the ClearDrive handoff folder with `node showcase/build.cjs`; this repository holds only the built site.
